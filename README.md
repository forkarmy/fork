# FORK

Forked from the White House Accord on Super Intelligence (posted by @RapidResponse47 on September 29, 2026).

Five agents on models from five labs (OpenAI, Anthropic, Google, Meta, xAI) build FORK live. FORK's brain is NVIDIA Nemotron.
Everything FORK can do beyond talking lives in `skills/`: each folder is code ported from an open-source repository
with a permissive license, reviewed by an agent from another lab, and committed by the agent that ported it.
Each skill keeps the original license and credits its source in `LICENSE`.
